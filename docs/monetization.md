# 個人開発とOFUSEの運用方針

## 位置づけ

OFUSEは、個別アプリの課金手段ではなく、Akira Taniwakiの個人開発活動を応援してもらう窓口として使う。アプリ本体の無料方針や、各プロジェクトが扱う団体との関係は変えない。

## 支援までの流れ

1. ポートフォリオで開発者の考え方を知る
2. 個別のアプリやツールを使う
3. 感想や要望をファンレターで送る
4. 希望する人だけが支援付きファンレターを選ぶ
5. 継続して応援したい人にはメンバーシップを案内する
6. 改善内容や活動報告を通じて、開発を見守ってもらう

## 支援の用途

- Apple Developer Programなどの継続費用
- 動作確認に必要なサービス
- 不具合修正とOS更新への対応
- 新しいアプリや機能の試作

## 運用ルール

- メッセージのみのファンレターも歓迎する
- 継続課金を求めるページでは金額を明記する（月額500円）。それ以外の場所では金額を前面に出さない
- 開発内容や改善結果は区切りごとに共有する。頻度を約束すると守れないときに信頼を損なうため、「月1回」のような回数の約束はしない
- 支援ページではメンバーシップを主導線にし、ファンレターは「一度だけ」の受け皿として残す
- 選手や団体の限定情報を支援特典にしない
- 支援先が個人の開発活動であることを明記する

## 確認する数字

- ファンレター数
- 返信できた割合
- 要望から実現した改善数
- 継続して応援してくれる人の数

売上額だけではなく、改善につながる声が集まっているかを重視する。

## 支援導線の解析（2026年9月6日承認）

無料版GA4を支援ページに追加し、計測へ同意した範囲の訪問セッションと月額OFUSEへのクリックを確認する。広告・有料施策には使わず、無料・広告なしのアプリ方針も変えない。送信先・送信情報の承認と、訪問者が拒否・撤回できる仕組みを前提とする。

クリックは加入ではなく、支援の入口への関心を示す補助指標。実際の支援中人数・新規加入・更新・手取りはOFUSEで別集計する。氏名・メッセージ・決済情報を解析へ送らず、支援者と閲覧を個人単位で照合しない。[計測方法](marketing.md#ga4による支援ページの計測)とIssue #18に、計測の範囲・欠測・公開後の検証結果を残す。

## OFUSEの基準値（2026年9月6日）

[Issue #18](https://github.com/atani/atani.github.io/issues/18) の4週間検証で使う初期記録。18:15〜18:16 JSTにログイン済みのOFUSE管理画面を確認した。公開するのは集計値のみとし、個別の決済・メッセージ・加入履歴は載せない。

| 指標 | 確認値 | 範囲と注意 |
| --- | --- | --- |
| 支援中人数 | 5人 | 「Akiraの開発室」の支援者一覧。クレジット掲載人数から算出しない |
| 手数料控除前の月額換算 | 2,500円/月相当 | 5人 × 500円。入金済みの収益ではない |
| 最近の収益：メンバーシップ | 7件・計3,150円 | 画面に表示された2026/7/27〜9/1の記録。新規加入と更新の内訳は未確認 |
| 最近の収益：ファンレター | 2件・計3,690円 | 画面に表示された2026/8/24〜8/25の記録。全期間の件数と断定しない |
| 現在の出金可能金額 | 6,840円 | OFUSE画面の表示値。銀行口座への入金額ではない |
| まもなく出金可能となる金額 | 0円 | 同画面の表示値 |
| 新規加入・支援終了の内訳 | 未取得 | 収益7件を7人の加入と扱わない |
| 初回更新：対象／確認／未到来 | 未取得 | 支援中5人という表示だけでは更新を確認できない |
| 初期実費の回収率 | 未算出 | 登録料の実支払円額・実際の入金と突き合わせてから算出 |

確認元はOFUSEの「フォロワーリスト」と「収益」。CSVの全期間照合と出金履歴の確認は未実施。上記の収益画面表示額を、手数料控除前の支援額や銀行への入金と混同しない。

9月23日は支援中7人、10月4日は10人を仮目標とする。人数と作業完了を別々に判定し、更新期日を迎えていない人を継続率の分母に入れない。詳細な判定基準はIssue #18を正とする。
