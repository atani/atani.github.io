# 個人開発とOFUSEの運用方針

## 位置づけ

OFUSEは、個別アプリの課金手段ではなく、Akira Taniwakiの個人開発活動を応援してもらう窓口として使う。アプリ本体の無料方針や、各プロジェクトが扱う団体との関係は変えない。

## 支援までの流れ

1. ポートフォリオで開発者の考え方を知る
2. 個別のアプリやツールを使う
3. 感想や要望をファンレターで送る
4. 希望する人だけが支援付きファンレターを選ぶ
5. 改善内容や活動報告を通じて、開発を見守ってもらう

## 支援の用途

- Apple Developer Programなどの継続費用
- 動作確認に必要な端末やサービス
- 不具合修正とOS更新への対応
- 新しいアプリや機能の試作

## 運用ルール

- メッセージのみのファンレターも歓迎する
- 支援金額を前面に出さない
- 月1回を上限に、開発内容や改善結果を共有する
- 選手や団体の限定情報を支援特典にしない
- 支援先が個人の開発活動であることを明記する

## 確認する数字

- ファンレター数
- 返信できた割合
- 要望から実現した改善数
- 継続して応援してくれる人の数

売上額だけではなく、改善につながる声が集まっているかを重視する。
