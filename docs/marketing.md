# ポートフォリオ運用計画

## 伝えること

「好きなものを、使い続けられる形に」を軸にする。完成品だけでなく、作った理由や改善の過程も伝える。

## 主な導線

- ポートフォリオから各製品ページへ移動する
- 各製品ページからポートフォリオの開発者紹介へ戻る
- ポートフォリオからOFUSEのファンレターへ移動する
- 不具合報告は各プロジェクトの窓口へ分ける

## 公開後の4週間

### 1週目

- ポートフォリオを公開する
- OFUSEプロフィールを作成する
- アンクラスPortの紹介ページから開発者ページへリンクする

### 2週目

- アンクラスPortを作った理由を紹介する
- Stockpileが解決している作業を紹介する

### 3週目

- 開発中のPeyoを紹介する
- 欲しいアプリや改善案をファンレターで募集する

### 4週目

- 届いた声から改善した内容を共有する
- ポートフォリオから各製品への移動数を確認する

## 計測

新しい解析サービスは追加しない。GitHub、App Store Connect、Chrome Web Store、OFUSEが提供する数字を使い、運用負担を増やさない。
